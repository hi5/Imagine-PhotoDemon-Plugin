# Imagine PhotoDemon Plugin

* 32/64 bit plugins PhotoDemon image format for the Imagine image viewer -- https://www.nyam.pe.kr/dev/imagine/
* Flattened view, supports transparency (checkered background)
* PhotoDemon graphics program https://photodemon.org/

Download the ZIP file under releases and copy PDI.plg + PDI.plg64 to Imagine's plugin folder (and restart Total Commander)

All code genereated by Claude by providing:

* Imagine plugin SDK and Link to Imagine website
* Link to PhotoDemon git repository https://github.com/tannerhelland/photodemon
